# 🧩 Sudoku Solver

A beautiful and fast **Flutter** application that solves any valid 9x9 Sudoku puzzle instantly using the **Backtracking Algorithm**. Simply input your puzzle, tap "Solve", and watch the magic happen!

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎯 **Instant Solving** | Solves any valid Sudoku puzzle in milliseconds |
| 🖊️ **Interactive Grid** | Tap any cell and input numbers using the built-in number pad |
| ✅ **Input Validation** | Detects invalid or duplicate entries before solving |
| 📋 **Sample Puzzle** | Load a pre-built puzzle with one tap to test the solver |
| 🎨 **Color Coding** | Original numbers shown in dark blue, solved numbers in green |
| 🌗 **Dark & Light Mode** | Automatically adapts to your phone's theme |
| 📱 **Custom App Icon** | Personalized launcher icon |
| 🔄 **Clear & Reset** | Clear the board and start fresh anytime |
| ✨ **Smooth Animations** | Beautiful transitions and scale effects |
